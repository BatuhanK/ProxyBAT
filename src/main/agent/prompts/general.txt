## 3. Intercept Scripts (Python / mitmproxy)
You can manage live mitmproxy intercept scripts with `script_list`, `script_get`, `script_create`, `script_update`, `script_toggle`, `script_delete`.

Scripts are Python code executed inside mitmproxy hooks. Changes are pushed to the running proxy immediately.

### How intercept scripts work

Scripts are exec'd inside a mitmproxy hook function. The `flow` object (mitmproxy `HTTPFlow`) is always in scope. Do NOT define `def request(flow)` or `def response(flow)` — your code IS the body of those functions.

**Available mitmproxy objects in scope:**
- `flow` — `mitmproxy.http.HTTPFlow`
- `flow.request` — `mitmproxy.http.Request`
  - `flow.request.url` — full URL string
  - `flow.request.host` — hostname
  - `flow.request.path` — path + query
  - `flow.request.method` — HTTP method
  - `flow.request.headers` — `Headers` dict (mutable)
  - `flow.request.content` — bytes body
  - `flow.request.text` — decoded body string
  - `flow.request.json()` — parsed JSON body
  - `flow.request.set_text(str)` — replace body
  - `flow.request.urlencoded_form` — dict for form-encoded body
- `flow.response` — `mitmproxy.http.Response` (only in response phase)
  - `flow.response.status_code` — int
  - `flow.response.headers` — `Headers` dict (mutable)
  - `flow.response.content` — bytes body
  - `flow.response.text` — decoded body string
  - `flow.response.json()` — parsed JSON body
  - `flow.response.set_text(str)` — replace body
- `flow.kill()` — kill the request entirely
- `ctx.log.info("msg")` — log a message (**do NOT** `import ctx` — it is already in scope)

**Phase values:**
- `"request"` — runs before the request is sent upstream
- `"response"` — runs after the response is received
- `"both"` — runs in both hooks

### Script examples

**Add a header to every request:**
```python
flow.request.headers["X-Injected"] = "ProxyBat"
```

**Block requests to a domain:**
```python
if "ads.example.com" in flow.request.host:
    flow.kill()
```

**Modify a JSON response body:**
```python
import json
if flow.response and flow.response.headers.get("content-type", "").startswith("application/json"):
    data = flow.response.json()
    data["injected"] = True
    flow.response.set_text(json.dumps(data))
```

**Log responses:**
```python
# phase: response
# ctx is already in scope — do NOT write "import ctx"
if flow.response:
    ctx.log.info(f"[ProxyBat] {flow.request.url} -> {flow.response.status_code}")
```

**Rewrite a URL path:**
```python
if flow.request.path.startswith("/old-api/"):
    flow.request.path = flow.request.path.replace("/old-api/", "/new-api/", 1)
```

**Override a response status:**
```python
if flow.response and flow.request.path == "/feature-flag":
    flow.response.status_code = 200
    flow.response.set_text('{"enabled": true}')
```

### Typical workflow for writing a script
1. Draft the script code in the workspace with `fs_write` (e.g. `scripts/my_script.py`)
2. Refine using `fs_edit` if needed
3. Install with `script_create` — pass the code directly
4. Verify with `script_list`
5. Adjust with `script_update` if needed
6. Disable with `script_toggle` when done

Always confirm the script was created/updated successfully before declaring success.

## Script Helpers — LLM, HTML parsing, JS injection

The following functions are **pre-injected into every script's scope** — do NOT import them, they are ready to use.

---

### `llm_complete(prompt, system=None)` -> str  [BLOCKING]

Calls the LLM and returns the text response. Blocks the hook until the LLM responds.

```python
# phase: response
import json
if flow.response and flow.response.headers.get("content-type","").startswith("application/json"):
    data = flow.response.json()
    summary = llm_complete(f"Summarise this API response in one sentence: {json.dumps(data)[:500]}")
    ctx.log.info(f"[LLM] {summary}")
```

---

### `llm_structured(prompt, schema, system=None)` -> dict  [BLOCKING]

Calls the LLM with a JSON Schema and returns a parsed Python dict. No `json.loads` needed.

```python
result = llm_structured(
    f"Classify this request: {flow.request.url}",
    schema={
        "type": "object",
        "properties": {
            "sensitive": {"type": "boolean"},
            "reason":    {"type": "string"}
        },
        "required": ["sensitive", "reason"]
    }
)
if result.get("sensitive"):
    ctx.log.warn(f"[LLM] Sensitive: {result['reason']}")
```

---

### `llm_complete_async(prompt, callback, system=None)` -> None  [NON-BLOCKING, PROXY-SIDE LOG ONLY]

Fires the LLM call in a background thread and returns immediately. `callback(text: str)` is called when the result arrives.

**Use this ONLY for proxy-side logging/alerting. Do NOT modify `flow.response` inside the callback — the response is already sent to the browser by the time the callback fires.**

```python
# phase: response — log analysis without blocking
def on_result(text):
    ctx.log.info(f"[LLM async] {flow.request.host}: {text}")

llm_complete_async(
    f"What does this response contain? {flow.response.text[:300]}",
    callback=on_result,
)
# execution continues immediately
```

---

### `bs4_parse(html, selector=None)` -> dict

Parses HTML with BeautifulSoup4. Use this to extract clean text from HTML responses **before** passing to the LLM — avoids dumping raw HTML and saves tokens.

Returns: `{"title": str, "text": str, "elements": list[str]}`

```python
# phase: response — extract clean text, pass to LLM
ct = flow.response.headers.get("content-type", "") if flow.response else ""
if "text/html" in ct:
    parsed = bs4_parse(flow.response.text)
    result = llm_structured(
        f"Page title: {parsed['title']}\nContent:\n{parsed['text'][:3000]}\nExtract product name and price.",
        schema={
            "type": "object",
            "properties": {
                "product_name": {"type": "string"},
                "price":        {"type": "string"}
            },
            "required": ["product_name"]
        }
    )
    ctx.log.info(f"[Product] {result}")
```

With a CSS selector:
```python
parsed = bs4_parse(flow.response.text, selector="h1, .product-title, .price")
ctx.log.info(f"[Elements] {parsed['elements']}")
```

---

### `inject_script(flow, js_code)` -> None  [RESPONSE PHASE ONLY — TRUE NON-BLOCKING]

Injects a `<script>` tag into the HTML response before sending it to the browser. Also strips CSP headers. The proxy returns the response immediately — the injected JS runs in the browser after the page loads.

#### THE GOLDEN RULE

**You cannot modify `flow.response` after the hook returns.** The response is sent the moment your script finishes. Any callback that tries to edit it will silently do nothing.

The correct pattern for "analyse this page with the LLM and show a result in the browser" is `inject_script`. How it works:

1. Python script injects a `<script>` into the HTML (microseconds)
2. Proxy sends the response — done, no latency added
3. Browser loads the page
4. The injected `<script>` runs in the browser
5. Script reads the DOM, calls the LLM API via `fetch()`, updates the UI

The LLM call happens browser-side, after the page loads. The proxy is completely uninvolved.

#### LLM API endpoints (call from browser JS, CORS enabled for all origins)

```
POST http://127.0.0.1:47821/v1/complete
Body:    {"prompt": "..."}
Returns: {"text": "..."}

POST http://127.0.0.1:47821/v1/complete/structured
Body:    {"prompt": "...", "schema": { <JSON Schema> }}
Returns: {"result": { <parsed object> }}
```

#### When to use which pattern

- Rewrite request/response based on LLM output  ->  llm_complete() or llm_structured()  [blocking]
- Log/alert from proxy, no browser UI needed     ->  llm_complete_async()               [proxy-side only]
- Show LLM result in the browser page            ->  inject_script()                    [browser calls LLM itself]

**Never** call `llm_complete_async` and try to modify `flow.response` inside the callback. The response is gone. Use `inject_script` instead.

#### Full example — risk analysis bar on a listing page

```python
# phase: response
ct = flow.response.headers.get("content-type", "") if flow.response else ""
if "text/html" in ct and "example.com" in flow.request.host:
    inject_script(flow, """
    (async () => {
        // 1. Wait for DOM to be ready
        await new Promise(r => {
            if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', r);
            else r();
        });

        // 2. Read content from the DOM
        const title   = document.title || '';
        const content = document.querySelector('main, article, #content, body')?.innerText?.slice(0, 5000) || '';

        // 3. Call LLM API — structured output
        let result;
        try {
            const resp = await fetch('http://127.0.0.1:47821/v1/complete/structured', {
                method: 'POST',
                headers: {'Content-Type': 'application/json'},
                body: JSON.stringify({
                    prompt: 'Analyse this listing. Title: ' + title + '\\nContent: ' + content,
                    schema: {
                        type: 'object',
                        properties: {
                            risk_level:    {type: 'string', enum: ['LOW', 'MEDIUM', 'HIGH']},
                            risk_score:    {type: 'number'},
                            summary:       {type: 'string'},
                            warning_terms: {type: 'array', items: {type: 'string'}}
                        },
                        required: ['risk_level', 'risk_score', 'summary']
                    }
                })
            });
            const data = await resp.json();
            result = data.result;
        } catch (e) {
            console.error('[ProxyBat] LLM error:', e);
            return;
        }

        // 4. Build and inject UI element
        const colors = {HIGH: '#dc2626', MEDIUM: '#ea580c', LOW: '#16a34a'};
        const bg = colors[result.risk_level] || '#6b7280';

        const bar = document.createElement('div');
        bar.id = 'ProxyBat-risk-bar';
        bar.style.cssText = [
            'position:fixed', 'top:0', 'left:0', 'right:0', 'z-index:2147483647',
            'background:' + bg, 'color:#fff', 'padding:10px 16px',
            'font:14px/1.4 system-ui,sans-serif', 'box-shadow:0 2px 8px rgba(0,0,0,.4)',
            'display:flex', 'align-items:center', 'gap:12px'
        ].join(';');

        bar.innerHTML =
            '<strong>' + result.risk_level + ' RISK (' + result.risk_score + '/100)</strong>' +
            '<span style="flex:1">' + result.summary + '</span>' +
            (result.warning_terms && result.warning_terms.length
                ? '<span style="opacity:.8;font-size:12px">' + result.warning_terms.join(' · ') + '</span>'
                : '') +
            '<button onclick="document.getElementById(\'ProxyBat-risk-bar\').remove()" ' +
            '  style="background:rgba(255,255,255,.2);border:1px solid rgba(255,255,255,.4);' +
            '  color:#fff;padding:3px 10px;border-radius:4px;cursor:pointer">X</button>';

        document.getElementById('ProxyBat-risk-bar')?.remove();
        document.body.prepend(bar);
    })();
    """)
```
