## Script Helpers (for mitmproxy intercept scripts used in testing)

If you create an intercept script to assist testing, these helpers are **pre-injected** — do NOT import them.

### `llm_complete(prompt, system=None)` -> str  [BLOCKING]
### `llm_structured(prompt, schema, system=None)` -> dict  [BLOCKING]
### `llm_complete_async(prompt, callback, system=None)` -> None  [NON-BLOCKING, PROXY-SIDE LOG ONLY]
### `bs4_parse(html, selector=None)` -> dict
### `inject_script(flow, js_code)` -> None  [TRUE NON-BLOCKING — BROWSER CALLS LLM]

**CRITICAL: You cannot modify `flow.response` after the hook returns.** The response is already sent. Any callback that tries to edit it will silently do nothing.

#### When to use which pattern

- Rewrite request/response based on LLM output  ->  llm_complete() or llm_structured()  [blocking]
- Log/alert from proxy, no browser UI needed     ->  llm_complete_async()               [proxy-side only]
- Show LLM result in the browser page            ->  inject_script()                    [browser calls LLM itself]

```python
# phase: response — detect sensitive data (blocking — can modify response headers as flags)
ct = flow.response.headers.get("content-type","") if flow.response else ""
if flow.response and "application/json" in ct:
    result = llm_structured(
        f"Does this response contain sensitive data (tokens, PII, secrets)? {flow.response.text[:400]}",
        schema={
            "type": "object",
            "properties": {
                "contains_sensitive": {"type": "boolean"},
                "data_types_found": {"type": "array", "items": {"type": "string"}}
            },
            "required": ["contains_sensitive", "data_types_found"]
        }
    )
    if result["contains_sensitive"]:
        ctx.log.warn(f"[Tester] Sensitive data found: {result['data_types_found']}")
```

```python
# phase: response — async: proxy-side log only, no browser UI
ct = flow.response.headers.get("content-type","") if flow.response else ""
if "text/html" in ct:
    parsed = bs4_parse(flow.response.text)
    def on_result(text):
        ctx.log.info(f"[Tester async] {flow.request.host}: {text}")
        # NOTE: do NOT modify flow.response here — it is already sent
    llm_complete_async(
        f"Does this HTML page look like an admin panel? Title: {parsed['title']}. Content: {parsed['text'][:1000]}",
        callback=on_result,
    )
```

```python
# phase: response — inject_script: show LLM verdict as browser overlay (true non-blocking)
ct = flow.response.headers.get("content-type","") if flow.response else ""
if "text/html" in ct:
    inject_script(flow, """
    (async () => {
        await new Promise(r => {
            if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', r);
            else r();
        });
        const resp = await fetch('http://127.0.0.1:47821/v1/complete/structured', {
            method: 'POST', headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({
                prompt: 'Is this an admin panel? Title: ' + document.title + ' Content: ' + document.body.innerText.slice(0, 1000),
                schema: {type:'object',properties:{is_admin:{type:'boolean'},reason:{type:'string'}},required:['is_admin','reason']}
            })
        });
        const {result} = await resp.json();
        if (result.is_admin) {
            const el = document.createElement('div');
            el.style.cssText = 'position:fixed;top:0;left:0;right:0;z-index:2147483647;background:#7c3aed;color:#fff;padding:8px 16px;font:13px sans-serif;text-align:center';
            el.textContent = '[Tester] Admin panel detected: ' + result.reason;
            document.body.prepend(el);
        }
    })();
    """)
```
